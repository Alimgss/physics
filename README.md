# برنامه‌ساز بدنسازی فارسی

یک اپ تک‌صفحه‌ای فارسی و راست‌به‌چپ برای ساخت برنامه بدنسازی چند هفته‌ای با کتابخانه گیف تمرین‌ها.

## اجرای پیش‌نمایش داخل محیط توسعه

```bash
npm run dev
```

سرور روی پورت `5173` اجرا می‌شود:

```text
http://localhost:5173/
```

> نکته مهم: اگر اپ داخل کانتینر یا محیط آنلاین اجرا می‌شود، آدرس `127.0.0.1` در مرورگر کامپیوتر شما به خود کامپیوتر شما اشاره می‌کند، نه کانتینر. در این حالت باید از بخش **Preview / Ports / Forwarded Ports** محیط، پورت `5173` را باز کنید و URL فورواردشده را استفاده کنید.

## اجرای مستقیم روی کامپیوتر خودتان

اگر می‌خواهید اپ روی کامپیوتر خودتان باز شود:

1. پروژه را روی کامپیوتر خودتان دانلود یا clone کنید.
2. داخل پوشه پروژه این دستور را اجرا کنید:

```bash
npm run dev
```

3. سپس در همان کامپیوتر این آدرس را باز کنید:

```text
http://localhost:5173/
```

## بررسی سلامت کد

```bash
npm run build
```
